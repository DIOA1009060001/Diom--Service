DIOM SERVICE – KIT PWA
======================

Fichiers à ajouter à la racine du dépôt GitHub, au même niveau que index.html :
- manifest.json
- service-worker.js
- offline.html
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Ensuite :
1. Ouvrir index.html dans GitHub.
2. Ajouter les lignes du fichier integration-index.txt aux emplacements indiqués.
3. Enregistrer avec Commit changes.
4. Attendre la publication GitHub Pages.
5. Tester le site dans Safari sur iPhone et Chrome sur Android.

Installation iPhone :
Safari > ouvrir le site > bouton Partager > Sur l’écran d’accueil > Ajouter.

Installation Android :
Chrome > ouvrir le site > menu ⋮ > Installer l’application (ou Ajouter à l’écran d’accueil).

Notes :
- Les fichiers doivent être placés à la racine du dépôt, pas dans un sous-dossier.
- Le service worker met en cache la page d'accueil et les ressources principales. Les commandes WhatsApp et les liens externes nécessitent Internet.
- Les icônes incluses sont des icônes provisoires DIOM SERVICE au monogramme DS. Tu peux les remplacer par ton logo officiel en gardant les noms et dimensions.
- GitHub Pages fournit HTTPS, nécessaire au fonctionnement du service worker.
- Une PWA installée n'est pas automatiquement publiée sur l'App Store ou Google Play.
